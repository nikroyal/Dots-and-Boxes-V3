## 2024-05-13 - Dashboard and Achievements Component Rendering Optimization
**Learning:** React re-renders components frequently when context like user profiles changes. Expensive operations, like O(N) filtering mapping arrays, and dynamically recalculating achievements within a render function without memoization, cause needless re-computations and impact performance.
**Action:** Extract O(N) operations inside components out of the render loop using React.useMemo hook, preventing their invocation when other uncorrelated parts of the state trigger component re-evaluations.
## 2024-05-13 - Component Rendering Optimization
**Learning:** Re-computing expensive logic or array iterations (like filtering/mapping) directly inside a React component render function can lead to slow performance due to the fact that React runs the render function frequently when any piece of its contextual state changes, including unrelated ones. In the dashboard and achievement lists, evaluating O(N) array loops to compute progress metrics on each render is an anti-pattern.
**Action:** Use React.useMemo hook to compute derived lists and properties out of the render loop. Memoize values depending on the specific profile variables or unlocked array, instead of blindly calculating progress metrics per-render block.
## 2024-05-13 - Dashboard and Achievements Component Rendering Optimization
**Learning:** Re-computing expensive logic or array iterations (like filtering/mapping) directly inside a React component render function can lead to slow performance due to the fact that React runs the render function frequently when any piece of its contextual state changes, including unrelated ones. In the dashboard and achievement lists, evaluating O(N) array loops to compute progress metrics on each render is an anti-pattern. Even worse, if you use useMemo but pass dependencies that get a new reference on every render (e.g. `const unlocked = profile.unlockedAchievements || []` where `unlocked` is passed to the dependency array), the useMemo will trigger on every render.
**Action:** Use React.useMemo hook to compute derived lists and properties out of the render loop. Memoize values depending on the specific profile variables, instead of blindly calculating progress metrics per-render block. Ensure that dependencies are stable across renders (like primitive types, or refs, or objects strictly managed by React state) to prevent breaking useMemo memoization.
